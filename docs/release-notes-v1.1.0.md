# TLockGUI v1.1.0

## 新功能

- 支持同时运行 1–8 个独立 `tle.exe`，默认并发数为 2。
- 并行队列为每个文件独立维护进度、日志、`.part`、退出状态和安全落盘流程。
- 支持取消表格中选中的运行中或等待中任务；停止全部会终止所有活动进程。
- 新增完整英语界面，覆盖状态、日志、错误提示、电源选项和覆盖确认；语言选择会持久保存。

## 安全与兼容性

- 已有目标文件的询问仍然串行处理，其他已启动任务可以继续运行。
- 覆盖、备份恢复、过期解锁时间停止、磁盘预检和 `.part` 防误覆盖规则保持不变。
- Windows 保持唤醒会覆盖整个并行批次；自动关机仍仅在没有失败或取消时触发。

## 建议

机械硬盘建议并发数设为 1；SSD 可从 2 开始测试。并发更高不一定更快，应同时观察磁盘吞吐、CPU 温度和 `tle.exe` 实际速度。
