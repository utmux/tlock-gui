# TLockGUI v1.0.0

首个公开版本，适用于 Windows 10/11 x64。

## 主要功能

- 使用官方 `drand/tlock` `tle.exe` 完成时间锁加密和解密。
- 支持多文件、拖拽、Unicode 与特殊字符路径、输出目录选择。
- 顺序任务队列、磁盘空间预检、安全 `.part` 落盘、覆盖保护和取消清理。
- 文件级及批量近似进度、速度、耗时、ETA、完整运行日志。
- 可选在处理期间阻止系统自动睡眠。
- 可选在全部任务成功完成后计划关机，并保留 60 秒取消时间。
- 后台流式计算 SHA-256。

## 下载与使用

下载 `TLockGUI-v1.0.0-windows-x64.zip`，解压后运行 `TLockGUI.exe`。发布包已经包含官方 `tle.exe`、Qt 动态库和适用的许可证文件，无需安装 Qt。

SHA-256 校验值见同一 Release 中的 `SHA256SUMS.txt`。

## 说明

- 首版一次运行一个 `tle.exe`。多任务并行计划在后续版本提供。
- 进度来自 `.part` 文件大小估算，可能不是线性的。
- 正式加密/解密及 `tle.exe --metadata` 需要能够访问 drand 网络。
