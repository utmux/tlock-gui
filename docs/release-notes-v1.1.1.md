# TLockGUI v1.1.1

## 改进

- 提前解密不再只显示笼统失败：现在会从 `tle.exe` 的诊断中读取目标轮次和当前轮次。
- 使用默认 quicknet 时，会换算并显示预计可解密的本地日期时间、时区和估计剩余时长。
- 同时保留目标轮次与当前轮次，便于排查节点同步或网络延迟。
- 批次结束弹窗会直接列出最多 3 条失败详情，不必再到日志中寻找提前解密原因。
- 英语界面同步支持新的详细提示。

## 说明

quicknet 按 3 秒周期估算。drand 节点同步和网络传输可能带来数秒延迟，因此到达显示时间后仍建议稍等片刻再重试。自定义网络若无法识别周期，则显示相差轮数而不猜测具体时间。
